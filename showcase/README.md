# Public showcase

This Storybook is the reproducible visual proof for WingmanPM Product Designer.
It is not included in the portable skill or npm runtime package.

```bash
npm --prefix showcase ci
npm --prefix showcase run storybook
npm --prefix showcase run capture
```

Every before/after pair uses the same fictional Tamarack Renewables copy,
sample data, actions, and viewport. The public `Maker Spotlight / WingmanPM`
story uses only the public identity, icon, headline, and product description
published at [wingman.pm](https://wingman.pm/). It contains no production data,
private screenshot, authentication route, checkout, or price.

The coastal wind-farm image was generated for this fictional concept. It does
not depict a real Tamarack Renewables site.
