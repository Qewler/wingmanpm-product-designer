## [1.1.0] - 2026-09-05

### Added

- Contextual anti-pattern guidance for excess text, headings, eyebrows, unclear
  action priority, and generic component-library composition.
- Component detail patterns for pending actions, anchored overlays, grouped help,
  feedback, selection, and gestures, with interruption and recovery checks.

- A quick rendered craft check for text contrast, overflow, runtime errors, and
  mobile navigation continuity, using an existing host or project browser.
- Nine searchable creative patterns with task strategy, signature, mobile
  translation, and risks; equal-fidelity exploration with distinct task flows.

- Cached stable-release checks and automatic updates for clean standalone skill
  installs, with integrity validation, atomic replacement, backups, local-edit
  protection, read-only mode, and native plugin-manager routing.
- Local visual exploration with comparable previews, responsive viewing, feedback,
  saved choice, immutable snapshots, and chat fallback across supported hosts.
- Small context output, dependency-aware proof plans, recorded command evidence,
  and explicit explore/build/ship stages.
- Real skills.sh copy/symlink install coverage, clean dependency build, and board
  browser checks. All supporting tools remain inside the portable skill folder.
- Observed execution evaluations that check actual file changes and scope.

### Changed

- Publisher display name is Wingman.PM / Qewler across Codex, the portable Cursor-compatible manifest, Claude marketplace metadata, npm, and skill attribution.
- Creative direction starts from the product task; numeric axes are optional.
- Ordinary design requests no longer require a style picker. Compound reviews
  load their relevant references and exact paths remain intact.
- Source-level taste heuristics are advisory. Punctuation and heading uniqueness
  are configurable project policy. Full accessibility evidence gates remain.
- Unrelated root notes no longer invalidate UI proof. Uncertain dependency
  resolution widens the check rather than silently dropping inputs.

### Fixed

- Browser test cleanup handles processes already stopped by a signal, reports
  startup failures, and uses a bounded shutdown instead of hanging Linux CI.

- Fresh React scaffolds declare the icon dependency their generated UI imports.
- Copied checkers execute correctly through symlinked project paths.


## [1.0.0] - 2026-08-31

### Added

- Public Agent Skill for designing, building, reviewing, polishing, and
  verifying responsive digital product interfaces.
- Portable Agent Plugins 1.0 manifest and native Codex and Claude Code plugin
  manifests.
- Codex and Claude Code marketplace metadata for the `wingmanpm` publisher.
- Safe command-line installation, upgrade, checks, and removal for supported
  coding-agent hosts.
- Public before-and-after showcase and reproducible browser evidence.
- Privacy, terms, support, and security documentation.

### Security

- Skills-only release with no MCP server, authentication, telemetry, remote
  code loader, or install-time lifecycle script.
- Content-hash protection for user-modified installed files.
