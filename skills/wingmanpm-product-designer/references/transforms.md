# Transformation Commands

Tie each transformation to the product task. Preserve protected business meaning.
Use before/after axes only when they explain a real visual choice. Record concrete
design changes rather than scores for their own sake.

## Intervention levels

- **Refine:** preserve the visual direction and information architecture. Fix
  hierarchy, spacing, type, states, alignment, contrast, and inconsistency.
- **Elevate:** include Refine, then add one product-specific signature moment
  that makes the main task clearer, faster, or more memorable.
- **Reimagine:** reconsider composition and system direction. Use [explore.md](explore.md) to compare two polished directions with the same
  content and brand limits, then build the selected direction. Honor a supplied
  count or prior user choice.

The selected level is a ceiling, not a quota. Keep a smaller change when that
fully solves the problem.

## `polish` / `beautiful`

Default level: **Refine**.

1. Find the three most visible sources of roughness in the requested surface.
2. Repair rhythm, hierarchy, control states, type roles, icon alignment, color
   use, and responsive edges using the established system.
3. Remove accidental inconsistency. Do not introduce a new visual thesis.
4. Apply [minimum craft](craft.md): measure text contrast and verify the mobile
   replacement for every existing route and task action. Compare both widths.

Success means the interface feels intentional while remaining recognizably the
same product. Expression usually stays fixed; other axes change only when the
current execution contradicts its own contract.

## `standout` / `stunning`

Default level: **Elevate**.

Use [creative patterns](creative-patterns.md) to find a task-based signature.
Complete the Polish pass, then identify the user's key object, decision, or
transition. Create one earned signature moment there. It can be a distinctive
composition, unusually clear data treatment, revealing interaction, purposeful
motion, or crafted component detail. It cannot be decorative noise, a generic
gradient, or a marketing hero placed inside routine product work.

Raise Expression only as far as the task tolerates. Repeated controls stay calm.
Motion can rise for the signature moment but must remain interruptible and have
a reduced-motion equivalent.

## `amplify` / `pimp`

Default level: **Elevate**, with a higher Expression target than Standout.

Strengthen contrast between primary and supporting regions, make the main
action unmistakable, sharpen key component details, and add restrained delight
where it confirms progress or exposes capability. Concentrate the increase in
one or two focal areas. Keep dense work regions stable and fast.

Do not respond by adding glow, gradients, shadows, animation, or rounded cards
everywhere. If the current design is already highly expressive, improve craft
instead of raising the axis.

## `calm` / `quieter`

Reduce competing accents, repeated borders, unnecessary elevation, redundant
labels, decorative motion, and equal-weight containers. Preserve visible
status, focus, errors, permissions, and the primary action. Lower Expression or
Motion only after proving that the task remains legible without those signals.

Success means attention has a clear path, not that the screen becomes pale or
featureless.

## `simplify` / `distill`

Map the task before removing anything. Separate essential decisions from
secondary detail, progressive disclosure, and true redundancy. Reduce steps,
simultaneous choices, repeated copy, and visual competition while keeping
capability discoverable and permission-safe.

Do not merge actions with different consequences. Do not hide errors, status,
provenance, pricing terms, or legal meaning. A shorter screen is not simpler if
the user must remember more or recover hidden context.

## Proof

For every transformation, capture before and after evidence at the affected
viewports. Verify focus, keyboard order, long content, loading, empty, error,
permission, and reduced-motion behavior where relevant. Explain the result in
terms of the task and observed changes, not subjective adjectives alone.
